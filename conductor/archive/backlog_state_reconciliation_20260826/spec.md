# Backlog state reconciliation

## Goal

Reconcile Conductor and GitHub issue states against current checksum-bound acquisition,
parser, licence and evidence outputs without converting genuine external or research gaps
into completed work.

## Acceptance criteria

- MBS TXT, PBS CSV, CMS CLFS, ASP and PFS parser/source-review items are implemented
  only when a reviewed bundle, successful validation and current rights evidence exist.
- Credentialed current PBS API parity remains blocked independently of the completed
  reviewed monthly extract parser validation.
- Five approved bounded analyses and claim packages are implemented within their scoped
  evidence contracts; full reports, papers and preprints remain separate open work.
- GitHub issues, generated drafts and Project rows agree with Conductor status.
- Repository generation and quality gates remain deterministic.

## Boundaries

No raw payload publication, source-rights expansion, research publication, paper,
preprint or external account mutation is authorized.
