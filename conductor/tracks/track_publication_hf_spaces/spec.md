# Hugging Face dataset and Spaces publication

## Scope

Validate and publish governed derived data and the static dashboard without
uploading raw restricted sources, credentials, papers or preprints.

## Acceptance criteria

- Dataset card and Croissant metadata preserve source-specific data rights.
- The Space declares Apache-2.0 for project code and `static` for the SDK.
- Candidate bundle, public-data policy and publication gates pass before mutation.
- Dataset and Space identity and metadata are verified after mutation.
- Redacted receipts record remote commit identifiers and exclude credentials.
