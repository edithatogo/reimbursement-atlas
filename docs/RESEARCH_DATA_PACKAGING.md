# Research-data packaging

The release-candidate research package is generated by
`scripts/make_research_package.py` from the governed publication manifest. It
contains three interoperable descriptors:

- `data/derived/research_package/datapackage.json` follows the Frictionless
  Data Package profile for permitted derived tabular resources.
- `data/derived/research_package/ro-crate-metadata.json` links the package to
  provenance, software, protocols and reports.
- `data/derived/research_package/dcat.jsonld` exposes catalogue metadata for
  discovery and interoperability.

The descriptors are deterministic, exclude themselves from their own resource
lists, and contain only repository-relative permitted paths. Raw or
licence-gated source payloads are not included. Apache-2.0 applies to project
software; derived data retain the source-specific rights and restrictions
recorded in the provenance and licence manifests.

This packaging track does not create a Zenodo DOI, publish a paper or submit a
preprint. Those actions remain separate release-gated workflows.
